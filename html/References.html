Description of JavaScript Code Functionality

The JavaScript validates the review form before submission. It prevents the default form submission, checks that the name and comment fields are not empty, and ensures the rating field is filled in and contains a valid number. If any field is invalid, an error message is displayed beside the corresponding input. A helper function (isNum) verifies that the rating is numeric. If all inputs are valid, the form is submitted programmatically. The script also creates a live countdown timer to a specific target date (July 30, 2026). It calculates the time remaining by subtracting the current date from the target date and converting the difference into days, hours, minutes, and seconds. These values are updated every second using setInterval, creating a real-time countdown effect on the webpage. The script also displays today’s current date in Canadian format (en-CA) when the page loads.
